APIキーの作り方
  1. 下のリンクから Google AI Studio を開き、Google アカウントでログインします。
  2. 「Get API key」→「Create API key」を押します。
  3. 表示された「AIza…」をコピーして、上の欄に貼り付け、「保存」を押します。

キーは Google AI Studio で無料で作れます。このブラウザの中にだけ保存され、Google 以外には送られません。無料枠に送った内容は、Google のサービス改善に使われることがあります。
